# Galaxy S23 Ultra — Landing Page

Одностраничный лендинг-концепт для Samsung Galaxy S23 Ultra. Учебный проект: чистый HTML/CSS/JS, без фреймворков и сборки.

## Структура проекта

```
nursat-improved/
├── index.html          # разметка страницы
├── style.css           # стили (тёмная тема, адаптив)
├── script.js           # интерактивность (конфигуратор, модалка, валидация)
├── package.json        # опциональный локальный сервер для запуска
├── .vscode/
│   ├── settings.json   # настройки редактора и Live Server
│   └── extensions.json # рекомендованные расширения VS Code
└── README.md
```

## Технологии

- **HTML5** — семантическая разметка
- **CSS3** — Flexbox, медиазапросы, CSS-переменные не используются намеренно (проект учебный, стили явные)
- **Vanilla JavaScript** — без библиотек: работа с DOM, событиями, валидация форм

## Функциональность

- Адаптивная навигация с мобильным меню (бургер)
- Плавный скролл по якорям
- Конфигуратор товара: выбор цвета и объёма памяти с динамическим пересчётом цены
- Модальное окно оформления предзаказа
- Валидация формы (имя, email, телефон) с выводом ошибок под полями
- Полностью адаптивная вёрстка (мобильные, планшеты, десктоп)

## Как запустить в VS Code

**Вариант 1 — Live Server (рекомендуется)**
1. Открой папку проекта в VS Code
2. Установи расширение **Live Server** (при открытии папки VS Code сам предложит установить рекомендованные расширения)
3. Кликни правой кнопкой на `index.html` → **Open with Live Server**
4. Страница откроется в браузере на `http://127.0.0.1:5500` и будет обновляться при сохранении файлов

**Вариант 2 — без расширений**
```bash
npm run start
```
Запустит локальный сервер через `http-server` (нужен Node.js) и откроет страницу в браузере.

**Вариант 3 — просто открыть файл**
Двойной клик по `index.html` тоже работает, но без автообновления и без некоторых относительных путей может понадобиться корректировка.
